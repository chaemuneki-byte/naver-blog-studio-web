처음 사용하시나요?

1. 글 생성 설정

연결 설정에 본인의 OpenAI API 키를 입력하세요. API 키는 새로고침하면 지워집니다. 참고 내용에는 확인된 사실이나 실제 경험을 적어 주세요. URL 본문을 가져오는 기능은 없습니다.

2. 네이버 연결 확장 설치

  1. 연결 확장 ZIP을 내려받아 압축을 풉니다.
  2. Chrome의 chrome://extensions 또는 Edge의 edge://extensions를 엽니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
  4. manifest.json이 있는 폴더를 선택하고 이 웹페이지를 새로고침합니다.

3. 원고 생성과 발행

블로그 ID를 설정하고 네이버에 로그인하세요. 키워드와 분량을 입력해 글을 만듭니다. ‘생성 후 자동 발행’을 켜면 생성부터 발행까지 이어집니다. 타이핑하는 동안 네이버 탭을 앞에 두고 편집기를 건드리지 마세요.

분량과 발행 설정

전체 500~10,000자, 목표의 ±5% 범위로 생성합니다. 소제목 아래 내용은 각각 200~300자입니다. 소제목은 번호와 줄바꿈으로 구분합니다. 이미지는 포함하지 않습니다. 발행에는 네이버에 현재 선택된 공개 범위와 카테고리를 사용합니다.

중지와 결과 확인

중지는 아직 전송하지 않은 입력을 멈춥니다. 최종 발행 버튼을 누른 뒤에는 이미 게시되었을 수 있습니다. 결과 미확인 상태에서는 자동 재발행하지 않습니다. 네이버에서 직접 확인하세요.

현재 검증 범위

웹 화면·글자 수 검사·모의 네이버 편집기 흐름을 검증했습니다. 실제 API 키와 로그인된 네이버에서의 발행은 미검증입니다. 네이버 편집기가 변경되면 확장의 선택자를 수정해야 할 수 있습니다.
