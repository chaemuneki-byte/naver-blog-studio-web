화면 연결 중…

네이버 입력은 암호화된 연결로 서버의 개인 브라우저에 전달됩니다. 연결 종료 시 로그인 세션이 삭제됩니다. 추가 인증은 직접 완료해 주세요.

설치 없이, 웹에서

1. 키워드로 원고 만들기

설정에 OpenAI API 키를 입력하고 주제와 분량을 정하세요. 소제목별 내용은 200~300자, 전체는 목표 ±5%로 작성합니다. 완성된 원고는 바로 수정하거나 복사할 수 있습니다. 참고 내용은 URL 대신 본문을 붙여넣어 주세요.

2. 웹에서 네이버 로그인

자동 발행 서버가 연결되면 이 사이트 안에서 개인 네이버 브라우저가 열립니다. 직접 로그인한 뒤 글쓰기 화면을 준비하세요. 확장 프로그램이나 북마크 등록은 필요하지 않습니다.

3. 입력부터 발행까지

‘생성 후 자동 발행’을 켜면 생성한 글을 한 글자씩 입력한 뒤 발행합니다. ‘네이버에 입력’은 입력까지만 합니다. 공개 범위와 카테고리는 네이버 발행 화면에 설정된 값을 사용합니다. 예시 원고는 발행할 수 없습니다.

현재 서비스 상태

GitHub Pages에서는 원고 생성과 편집을 제공합니다. 자동 발행은 별도 브라우저 서버를 배포한 주소에서 사용할 수 있습니다. 실제 네이버 로그인·발행은 아직 검증되지 않았으며, 편집기 변경이나 추가 인증으로 작업이 멈출 수 있습니다.

중지와 재시도

중지하면 이후 입력을 멈춥니다. 발행 버튼이 이미 눌렸다면 게시가 완료되었을 수 있습니다. 결과 미확인 상태에서는 자동 재발행하지 않으니 네이버에서 확인해 주세요.
