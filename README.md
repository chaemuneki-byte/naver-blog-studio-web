# 블로그 스튜디오 2 — 설치 없는 웹 에디터

[웹사이트](https://chaemuneki-byte.github.io/naver-blog-studio-web/)

키워드·목표 분량을 입력하면 제목과 소제목별 200~300자 원고를 작성합니다. 2.0에서는 확장 프로그램 연결을 제거하고 **서버에서 실행되는 개인 브라우저**를 웹에서 조작하는 방식으로 변경했습니다. 화면도 가로형 탐색 메뉴, 보라색 강조색, 넓은 원고 편집 영역으로 다시 구성했습니다.

## 지금 사용할 수 있는 것

| 기능 | GitHub Pages | 브라우저 서버 배포 후 |
|---|---|---|
| 키워드로 제목·본문 생성 | 가능 · OpenAI API 키 필요 | 가능 |
| 목표 분량/소제목별 200~300자 검사 | 가능 | 가능 |
| 원고 수정·복사·TXT 저장 | 가능 | 가능 |
| 웹 안에서 네이버 로그인 | 불가 | 구현됨 · 실제 네이버 검증 필요 |
| 순차 타이핑·자동 발행·중지 | 불가 | 구현됨 · 실제 네이버 검증 필요 |

**현재 공개 주소는 GitHub Pages의 원고 작성 모드입니다. 브라우저 서버는 아직 공개 호스팅에 배포하지 않았습니다.** 서버가 없을 때는 자동 발행을 비활성화하며, 연결된 것처럼 표시하지 않습니다. GitHub Pages는 HTML/CSS/JavaScript를 제공하는 정적 호스팅이므로 로그인 세션을 가진 Chromium을 실행할 수 없습니다.

## 사용자 흐름

1. 웹페이지의 설정에 OpenAI API 키를 입력합니다. 별도 프로그램 설치는 필요 없습니다.
2. 서버가 배포된 사이트에서는 운영자가 정한 접속 코드로 개인 브라우저를 엽니다. 별도 회원가입은 없습니다.
3. 웹 안의 네이버 화면에서 입력란을 클릭한 뒤 하단 입력란으로 ID·비밀번호를 전달합니다. 네이버 추가 인증은 직접 완료합니다.
4. 본인 블로그 ID를 설정하고 **글쓰기 열기**를 누릅니다.
5. 키워드·분량을 입력하고 원고를 생성합니다. **생성 후 자동 발행**을 켜면 제목·본문을 순차 입력한 뒤 발행합니다.
6. **연결 종료**는 서버 브라우저와 로그인 세션을 삭제합니다. 창 닫기는 화면만 닫습니다. 자동 입력 중에는 브라우저 수동 조작을 차단합니다.

원고 전체 글자 수는 제목·줄바꿈 제외, 소제목·공백 포함이며 목표 ±5%입니다. 소제목 아래 내용마다 200~300자를 적용합니다. 참고 자료에 없는 실제 경험·통계·최신 사실을 꾸며내지 않도록 요청합니다. 참고 URL 자동 수집이나 이미지 생성은 포함하지 않습니다. 예시 원고는 발행할 수 없습니다.

## 서버 배포 — 운영자용

방문자가 설치할 것은 없습니다. 아래 작업은 서비스를 운영할 서버에서 한 번 수행합니다. Linux Docker 호스트, 본인 도메인, HTTPS, Chromium sandbox를 실행할 수 있는 환경이 필요합니다. 짧은 실행시간으로 제한되는 함수형 호스팅에는 적합하지 않습니다. 브라우저 1~2개를 위한 메모리를 확보하고 호스트에서 실제 사용량을 확인하세요.

1. 저장소를 Linux 서버로 가져옵니다.
2. 도메인의 DNS를 서버로 연결하고 80/443 포트를 엽니다.
3. `.env.example`을 `.env`로 복사합니다. `STUDIO_DOMAIN`에 도메인만 입력하고 `STUDIO_ACCESS_CODE`를 충분히 긴 무작위 값으로 교체합니다.
4. `docker compose up -d --build`로 실행합니다. Caddy가 HTTPS를 제공합니다. 서비스는 `/app/data`의 영구 볼륨에 중복 발행 방지 기록만 보관합니다.
5. `https://설정한도메인`에서 전체 웹앱을 사용합니다. API는 같은 출처에서만 접근하도록 설계되어 있습니다. GitHub Pages가 다른 서버의 로그인 토큰을 보내는 구조가 아닙니다.

Playwright 공식 이미지와 패키지 버전을 1.62.0으로 일치시켰습니다. 컨테이너는 `pwuser`, Chromium sandbox, 공식 seccomp 프로필을 사용합니다. Linux 호스트의 user namespace 정책에 따라 추가 설정이 필요할 수 있습니다. sandbox 실행에 실패하면 연결을 거부하며 자동으로 sandbox를 해제하지 않습니다. Docker/Linux 배포는 현재 환경에서 검증하지 못했습니다.

**개인 운영용 단일 프로세스 서비스**입니다. Uvicorn은 반드시 worker 1개로 실행하세요. 여러 사용자가 가입하는 공개 SaaS용 계정 관리·과금·테넌트별 프로세스 격리는 포함하지 않습니다. 접속 코드는 비공개로 보관하고 TLS 프록시 외에 8000 포트를 인터넷에 공개하지 마세요.

## 데이터와 발행 처리

- OpenAI 키는 브라우저 탭 메모리에만 있습니다. OpenAI API로 직접 보내며 서버에 저장하지 않습니다.
- 서버 접속 토큰도 탭 메모리에만 있고 URL·localStorage에 저장하지 않습니다.
- 네이버 입력은 TLS를 통해 해당 세션의 브라우저로 전달됩니다. 서버 운영자는 이 환경을 신뢰할 수 있게 관리해야 합니다. 요청 본문, 로그인 입력, 스크린샷을 로그/파일로 저장하지 않습니다.
- 브라우저 컨텍스트는 세션별 분리, 동시에 최대 2개입니다. 유휴 30분 또는 생성 후 2시간에 정리합니다. 탭을 새로고침하면 토큰을 잃어 기존 세션은 만료까지 남을 수 있습니다.
- 서버 브라우저는 HTTPS 네이버 도메인과 관련 정적 자원만 요청할 수 있습니다. 임의 URL 실행 API, 확장 프로그램, CAPTCHA 우회 기능은 없습니다.
- 기존 내용이 있는 편집기는 덮어쓰지 않습니다. 완성 원고와 일치하면 ‘입력만’ 이후 발행을 이어갈 수 있습니다.
- 실제 입력 내용과 원고를 대조한 뒤 발행합니다. 최종 클릭 전에 SQLite에 원고·블로그 해시를 기록합니다. 재시작하거나 결과가 불명확해도 같은 원고를 자동 재발행하지 않습니다.
- 공개 범위·카테고리는 네이버 화면의 현재 설정을 사용합니다. 최종 클릭 이후에는 중지가 게시를 취소하지 못할 수 있습니다.

## 개발과 검증

정적 화면: `npm run serve` → `http://127.0.0.1:4173`

서버: Python 3.12 이상, `pip install -r requirements-dev.txt` 및 `playwright install chromium`. `STUDIO_ACCESS_CODE`에 24자 이상 코드, `PUBLIC_ORIGIN=http://127.0.0.1:8000`을 설정한 뒤 `python -m uvicorn server.app:create_app --factory --host 127.0.0.1 --port 8000 --workers 1 --no-access-log`를 실행합니다. 로컬 테스트만 HTTP를 허용합니다. Windows에서 설치된 Edge로 시험하려면 `BROWSER_CHANNEL=msedge`를 사용합니다.

- `npm test`: 원고 생성·검사 및 이전 확장 회귀 테스트
- `python -m unittest discover -s tests -p server_test.py -v`: 서버 인증·세션·요청 제한·발행 어댑터 테스트
- 정적 서버 실행 후 `python tests/web_fixture.py`: API 응답을 대체한 웹 화면 테스트
- `python tests/remote_web_fixture.py`: 원격 브라우저 API를 대체한 웹 연결 테스트

네이버/OpenAI 실제 요청 없이 로컬 모의 응답으로 테스트합니다. **실제 네이버 로그인, 추가 인증, 스마트에디터 선택자, 실제 발행 및 Linux 컨테이너 구동은 미검증**입니다. 배포 후 소유한 테스트 블로그에서 입력 전용 모드부터 확인해야 합니다. 기존 `extension/` 소스는 이전 버전 회귀 검사용으로 남아 있지만 새 웹앱은 사용하지 않습니다.

참고: [GitHub Pages 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Playwright Docker 문서](https://playwright.dev/python/docs/docker). `server/seccomp_profile.json`은 Microsoft Playwright v1.62.0의 공식 프로필입니다.
